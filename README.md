# Vitrine Virtual

Projeto de uma vitrine virtual de produtos artesanais, desenvolvido como projeto de estudo e portfólio durante o curso de Análise e Desenvolvimento de Sistemas (ADS).

## Sobre o projeto

A Vitrine Virtual tem como proposta apresentar produtos artesanais de forma simples e organizada, permitindo que o cliente conheça os produtos, selecione aqueles de seu interesse e entre em contato com o responsável pela loja por meio do WhatsApp.

O projeto foi pensado inicialmente a partir de uma necessidade real, mas sua primeira versão terá caráter de estudo e portfólio.

## Objetivos
- Aplicar na prática os conhecimentos adquiridos durante o curso de ADS
- Desenvolver um projeto completo partindo do levantamento de requisitos
- Praticar organização, documentação e desenvolvimento de software
- Criar um projeto que possa evoluir futuramente.
## Funcionalidades planejadas
### Cliente
- Visualização dos produtos
- Visualização dos detalhes de cada produto
- Seleção de produtos de interesse
- Alteração da quantidade selecionada
- Remoção de produtos da seleção
- Persistência da seleção
- Envio da seleção para o WhatsApp.
### Responsável pela loja
- Cadastro de produtos
- Edição de produtos
- Remoção de produtos
- Gerenciamento de preços
- Gerenciamento de disponibilidade
- Gerenciamento de imagens
- Definição de prazo estimado de produção
- Futuramente, controle de estoque.

## Fora do escopo inicial
A primeira versão não terá:

- Pagamento online
- Sistema de checkout
- Cadastro de clientes
- Login para clientes
- Cálculo de frete
- Aplicativo mobile
- Sistema próprio de mensagens

A negociação e eventual compra serão realizadas diretamente entre cliente e responsável pela loja, utilizando o WhatsApp.
